# Plov Express 🍚

Static ordering demo: menu → cart → checkout → live tracking → rating. No build step, single `index.html`.

## Deploy to GitHub Pages
1. Create a repo and push these files to the `main` branch root.
2. Repo **Settings → Pages → Build and deployment**: Source **Deploy from a branch**, Branch `main`, folder `/ (root)`.
3. Open `https://<user>.github.io/<repo>/` after a minute.

Files: `index.html` (app) · `404.html` (redirects unknown URLs home) · `.nojekyll` (skips Jekyll) · `robots.txt`.
